# DESIGN.md

## 1. Структуры данных и алгоритмы

### Секретное число — `generateSecret`

- **Тип:** `string` (например, `'0123'`).
- **Почему не `number`:** число `0123` становится `123` — лидирующие нули теряются. Строка их сохраняет.
- **Алгоритм:** Fisher-Yates Shuffle (перемешивание).
  1. Берём срез алфавита для базы: `DICT.slice(0, base)` → `'0123456789'` (base 10).
  2. Копируем в массив и перемешиваем **in-place** (быстро, без аллокаций).
  3. Берём первые `length` элементов → `.join('')`.
- **Случайность:** инжектируется параметром `random: () => number`.
  - Тесты: детерминированная функция `() => 0.5`.
  - Прод: дефолт `Math.random`.

---

### Валидация ввода — `isValidGuess` + `createDigitValidator`

- **Алфавит базы:** `Set<string>` — проверка вхождения за **O(1)**.
- **`createDigitValidator(base)`** — каррированная фабрика. Возвращает предикат `(char) => boolean`, замыкающий `Set` алфавита (в нижнем регистре).
- **`isValidGuess`** — три последовательные проверки:
  1. Длина: `guess.length === length`.
  2. Символы: каждый `char` проходит валидатор фабрики.
  3. Уникальность: `new Set(guess.toLowerCase()).size === length`.
- **Регистр:** везде `toLowerCase()` — `'A'` и `'a'` считаются одной цифрой.

---

### Оценка попытки — `evaluateGuess`

- **Вход:** `secret: string`, `guess: string` (уже в нижнем регистре).
- **Алгоритм (один `reduce`):**
  1. Идём по индексам секрета.
  2. `sChar === gChar` → `bulls++`.
  3. Иначе → пушим в массивы остатков: `secretRest`, `guessRest`.
- **Коровы:** после reduce делаем `Set(secretRest)`, считаем `guessRest.filter(ch => set.has(ch)).length`.
- **Ключ:** быки отсекаются сразу, чтобы не посчитать их повторно как коров.

---

### Количество вариантов — `countPossibleSecrets`

- **Формула:** перестановки `P(n, k) = n! / (n-k)! = n * (n-1) * ... * (n-k+1)`.
- **Рекурсия:** `P(n, k) = n * P(n-1, k-1)`.
- **Базовые случаи:**
  - `k === 0` → `1`.
  - `k === n` → `n!` (берём из Lookup Table).
- **Lookup Table:** `const FACTORIAL = [1, 1, 2, 6, 24, ... 16!]` — доступ `O(1)`.
- **Мемоизация:** `Map<string, number>` с ключом `"${length}:${base}"`. Повторный вызов — `O(1)`.

## 2. Сложность (Big O)

| Функция                    | Time                                     | Space       | Обоснование                                                                                        |
| :------------------------- | :--------------------------------------- | :---------- | :------------------------------------------------------------------------------------------------- |
| **`generateSecret`**       | **O(base)**                              | **O(base)** | Fisher-Yates: `base-1` итераций (max 16). Копия пула `O(base)`.                                    |
| **`evaluateGuess`**        | **O(L)**                                 | **O(L)**    | Один `reduce` по длине `L` (max 6) + `filter` по остатку + `Set`. Нет вложенных циклов.            |
| **`isValidGuess`**         | **O(L)**                                 | **O(base)** | Длина `O(1)`, проход по строке `O(L)` с `Set.has` `O(1)`. Алфавит в `Set` создаётся 1 раз на базу. |
| **`countPossibleSecrets`** | **O(length)** (1-й)<br>**O(1)** (cached) | **O(1)**    | Рекурсия глубиной `length` (≤6). База `k===n` → `FACTORIAL[base]` `O(1)`. Кэш `Map` ≤ 20 записей.  |

> **Все параметры ограничены типами:** `LengthType = 2..6`, `BaseType = 2\|8\|10\|16`. Любая «сложность» — константа ≤ 22 вызова.

## 3. Принципы чистого кода — файл / функция / что сделано

| Принцип                         | Где                                                       | Реализация                                                                                                                                 |
| :------------------------------ | :-------------------------------------------------------- | :----------------------------------------------------------------------------------------------------------------------------------------- |
| **Pure Functions**              | `generateSecret`, `evaluateGuess`, `countPossibleSecrets` | Нет сайд-эффектов. Результат только от аргументов. Кэш инкапсулирован.                                                                     |
| **Dependency Injection**        | `generateSecret(..., random = Math.random)`               | `random` — параметр. Тесты передают свой мок.                                                                                              |
| **Single Responsibility (SRP)** | `createDigitValidator` / `isValidGuess`                   | Валидатор **только** алфавит. `isValidGuess` **только** оркестрация проверок.                                                              |
| **Immutability**                | Все `.ts` в `core/`                                       | Нет `let`/`var` для данных. `reduce`/`map`/`filter` вместо циклов. Локальная мутация массива в `generateSecret` изолирована (`[...pool]`). |
| **Functional Core**             | `core/*.ts`                                               | Вся логика — чистые функции. Shell (CLI/UI) — снаружи.                                                                                     |
| **Currying / HOF**              | `createDigitValidator(base)(char)`                        | Фабрика возвращает специализированную функцию. Готово для real-time ввода.                                                                 |
| **Domain Types**                | `types.ts`                                                | `type SecretLength = 2\|3\|4\|5\|6` — невалидное состояние **не компилируется**.                                                           |
| **No Magic Numbers**            | `DICT`, `FACTORIAL`                                       | Именованные константы вместо литералов.                                                                                                    |
| **Fail Fast**                   | `countPossibleSecrets`, `isValidGuess`                    | Гварды в начале: `if (len > base) throw...`.                                                                                               |
| **Lookup Table**                | `countPossibleSecrets::FACTORIAL`                         | Массив вместо рекурсивного факториала. `O(1)`, нет стека, читаемо.                                                                         |
| **Testability (TDD)**           | Все модули                                                | Чистые + типы = мгновенные детерминированные тесты без моков фреймворков.                                                                  |
